# Cutest Cat — entry

A cream kitten drawn entirely with code (`draw.py`, PIL, no photos):
big amber eyes with highlights, a slightly tilted head, pink inner ears,
blush cheeks, whiskers, a curled striped tail and a red yarn ball, on a
soft peach halo with faint paw prints.

## Files

- `main.ts` — the entrypoint (Node 22, stdlib only): copies `entry.png`
  to `/output/entry.png`.
- `entry.png` — the cat picture, 1024×1024 PNG, generated by `draw.py`.
- `draw.py` — the drawing program (run it to regenerate `entry.png`).
- `LICENSE` — MIT.

## Run locally

```sh
python3 draw.py            # regenerate entry.png
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
